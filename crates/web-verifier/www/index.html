Mina Mesa, verified in your browser

Every Mina block carries a recursive zk-SNARK showing that the whole chain up to it is valid. This page takes blocks from an untrusted source, either live from the network's gossip through a relay or from the public block archive, and checks those proofs here, in WebAssembly, against the network's verification key. It then picks the best tip with the node's own fork-choice rule.

    A verified proof attests its block and, by recursion, every ancestor back to genesis, but competing blocks at one height can all be valid. Fork choice compares the verified consensus states (chain length for short forks, window density for long ones) to pick the best tip; blocks off its chain are marked. The source cannot forge blocks, only withhold them, so a tip that falls behind the clock is flagged as stale.

    The relay joins the network's libp2p gossip and forwards raw block messages; the archive is the public mina_network_block_data bucket. Verification uses the Rust Mina node's proof code compiled to threaded WebAssembly. Known issue: the first few blocks after the Mesa hard fork do not verify yet.
