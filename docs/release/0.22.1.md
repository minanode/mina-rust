# minanode 0.22.1 release notes

0.22.1 is a UI release. It has a design pass over the node dashboard and the web
node page, and one dashboard wording fix. The node, consensus, p2p, ledger and
prover code are unchanged from 0.22.0. Upgrading is optional. It is a beta
release. The web node runs on devnet only. Use only devnet keys in it.

## Dashboard and web node page

The node dashboard and the web node page have a new design ([#43]). The design
pass covered every page in the dark theme, the light theme and a phone layout.

- Navigation is grouped. Labels are short, and values are in mono.
- Every wide table has a phone layout, among them the blocks, peers, SNARK jobs
  and won slots tables.
- The dashboard's Block producer page puts the won slots on one axis. Each won
  slot has a Stages panel with its block's stages and their times.
- The web node's Start-up page says when start-up is paused, has failed or is
  blocked by the page.
- When the web node stops answering, its figures say they are from the last
  answer, and the banner has Reload.
- minanode.org keeps its look.

The native binary embeds the dashboard and serves it on the node's HTTP port,
`http://127.0.0.1:3000` by default. After you upgrade, the same address shows
the new dashboard. The Docker image has the same binary.
[The dashboard](https://minanode.org/docs/dashboard/) describes each page.

minaweb.org runs this release's web node page. The relay code is unchanged from
0.22.0. `mina-web-0.22.1.tar.gz` runs the same page from your own computer,
through the same two relays.
[Run the web node yourself](https://minanode.org/docs/run-web-node/) has the
steps.

## Dashboard wording fix

On the Block producer page, the reason for `BestTipSuperior` now says "Another
block won. Ours was never sent." The node drops a won slot for this reason when
the best tip beats its block before the block is sent. 0.22.0 called it a
tie-break for the slot, but the best tip also wins with a longer chain. At equal
length, fork choice compares the VRF output before the state hash. The label,
Lost the tie, is unchanged.

## Upgrade from 0.22.0

To get the new dashboard, replace the binary as the
[install guide](https://minanode.org/docs/install/#upgrading) describes. Start
the node with the same work directory and flags. 0.22.1 needs no state
migration. A 0.22.0 node that you don't upgrade keeps working as before.

With Docker, pull `ghcr.io/minanode/mina-rust:0.22.1` and check its digest, as
[Docker](https://minanode.org/docs/docker/#stop-and-upgrade) describes.
