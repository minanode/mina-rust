# Fonts

Self-hosted variable fonts, Latin and Latin Extended subsets only, used through
`../styles/fonts.css`.

| File                                         | Font                            | Licence                                                |
| -------------------------------------------- | ------------------------------- | ------------------------------------------------------ |
| `inter-latin-wght-normal.woff2`              | Inter, weights 100–900          | SIL Open Font License 1.1, `LICENSE-Inter.txt`         |
| `inter-latin-ext-wght-normal.woff2`          | Inter, weights 100–900          | SIL Open Font License 1.1, `LICENSE-Inter.txt`         |
| `jetbrains-mono-latin-wght-normal.woff2`     | JetBrains Mono, weights 100–800 | SIL Open Font License 1.1, `LICENSE-JetBrainsMono.txt` |
| `jetbrains-mono-latin-ext-wght-normal.woff2` | JetBrains Mono, weights 100–800 | SIL Open Font License 1.1, `LICENSE-JetBrainsMono.txt` |

The files are copied unchanged from `@fontsource-variable/inter` 5.3.0 and
`@fontsource-variable/jetbrains-mono` 5.3.0. The licence files are those
packages' `LICENSE` files: each holds the copyright notice and the full OFL 1.1
text.

The OFL lets the fonts be bundled and served with any software, provided the
copyright notice and licence go with them. Keep the two licence files next to
the fonts, and ship them with any app that serves the fonts. minanode.org
publishes them at `/licenses/fonts.txt`; the dashboard should do the same.
