# Run with Docker

The community release image is `ghcr.io/minanode/mina-rust:0.20.0`. It contains
the native node and its built-in dashboard. For supported platforms, volume
ownership, port bindings and role-specific Compose examples, follow
[the current Docker guide](https://minanode.org/docs/docker/).

The old Docker Hub node and standalone frontend examples have been retired from
this guide. Historical upstream tags do not describe the community release.
